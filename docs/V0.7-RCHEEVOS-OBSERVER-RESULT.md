# v0.7 rcheevos observer definition layer — validation result

The observer definition layer is validated and ready to merge.

## Proven behavior

- Raw RetroAchievements achievement definitions can be activated through the Electron observer service into the native `rc_runtime` helper.
- A game session is sealed only after every definition activates successfully.
- Partial loads are rolled back on parse/activation failure.
- Live evaluation is blocked when attached Dolphin memory does not match the expected GameCube game code.
- A native helper restart invalidates the sealed observer session, requiring definitions to be reloaded.
- Runtime states, measured progress and local trigger events remain observer-only; official RetroAchievements server state is the sole Completed/Locked authority.
- No RA gameplay session, unlock submission, leaderboard submission or Dolphin memory write is performed.
